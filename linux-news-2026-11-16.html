Linux 7.4-rc3 发布：Linus 称「各处照例都是噪音」
内核 kernel
Linux 7.4 的第三个每周候选版本（rc3）发布。Linus Torvalds 在公告中写道：「又是常规的一周、又一个体量不小的 -rc」——驱动（网络与 GPU）继续领跑修复量，但绝大多数补丁本身都很小；文件系统因为几个较大的补丁在 diffstat 里显眼，其中一个是 iomap 的调用约定变更（改动虽大但相当简单），另有一批 SMB 客户端修复；此外还有自测（selftests）与文档更新。按计划，Linux 7.4 正式版预计 12 月底前后发布。
关注理由：7.4 是当前合并窗口之后的主线节奏点，年底正式版将承载近期大量 GPU/驱动工作（如 NVIDIA Nova、Intel/NVIDIA 新使能）；跟踪 rc 期回归情况对内核升级规划有直接参考价值。

AMD 发布混合架构 CPU 的 Capacity Aware Scheduling 补丁：大小核终于不再被「一视同仁」
内核 kernel
AMD 工程师 posted 一组 Linux 内核补丁，为 AMD 异构/混合处理器启用容量感知调度（Capacity Aware Scheduling）。现状是：amd-pstate 频率驱动目前不导出每核 capacity 指标，调度器把所有核心视为同等算力，性能核与能效核被随意混用，在混合系统上同时损害吞吐与能效；随着传闻中面向部分 Zen 6 Ryzen 的低功耗核心类型加入，问题会更突出。新补丁让 amd-pstate 发布非对称的 per-CPU capacity 并在支持的硬件上默认启用，可用新启动参数 amd_case=disable 关闭。若评审顺利，有望赶上 Linux 7.5 周期。
关注理由：Intel 侧的 ITMT/capacity 感知早已就位，AMD 大小核调度补齐是 Ryzen AI/混合平台 Linux 体验的关键一环；对终端调度性能与能效调优都是值得基准测试的变化。

AMD ARG「AMD Root Guest」：EPYC 9006 机密计算新特性，Linux 补丁预计 2027 Q1
计算 compute
KVM Forum 2026（温哥华）上，AMD 的 David Kaplan 与 Tom Lendacky 介绍了 AMD Root Guest（ARG）——EPYC 9006「Venice」服务器 CPU 的新特性，此前几乎没有公开讨论，AMD 同期也发布了技术白皮书。ARG 目标是改善 SEV-SNP 受保护虚拟机的实时迁移（live migration）体验，且不需要改动 guest 镜像或 guest 操作系统；其形态是一个带提升特权、有信任根基（root of trust）的签名 SEV-SNP VM，每系统仅允许一个活跃 ARG。Linux 使能仍在原型阶段，AMD 预计首批补丁 2027 年 Q1 前后发布。
关注理由：机密计算（SEV-SNP）是云上敏感负载的主流方案，而 live migration 一直是其运维痛点；ARG 从硬件层解决该问题，对部署 AMD 机密计算的大规模云环境是重要路线图信息。

华硕 Ascent QN10 迷你主机（骁龙 X2 Elite）开始获得 Linux 支持：0.7L 带动 4×4K
显示 display
继多款骁龙 X2 笔记本之后，高通工程师提交了华硕 Ascent QN10 迷你主机的 Linux bring-up 补丁：基于骁龙 X2 Elite（Glymur）平台，18 核 Oryon CPU + Adreno X2-90 GPU + Hexagon NPU，最高 32GB LPDDR5x-9600 内存、双 M.2 NVMe、Wi-Fi 7、2.5GbE，体积不到 0.7 升，可驱动最多 4 台 4K 显示器（HDMI 经 eDP + PS195 转换器输出），起售价 1699 美元。补丁让该机可正常启动 Linux 并点亮全部关键功能，目标赶上 Linux 7.5 合并周期。
关注理由：ARM 桌面/迷你主机生态继续扩张；对显示与 GPU 方向而言，Adreno X2 的 DRM/显示通路 bring-up 细节（含 eDP 转 HDMI 方案）值得参考，也是 X2 平台上游化进度的又一标志。

IBM s390 硬件加速跑 ARM64 虚拟机：「双架构」方案在 KVM Forum 详解
计算 compute
继 IBM 与 Arm 合作「双架构」硬件的消息之后，IBM 工程师 Steffen Eiden 在 KVM Forum 2026 上详解了 在 s390 大型机上以硬件加速方式运行 ARM64 guest 虚拟机的方案：除 s390 硬件侧外，还需要 KVM 虚拟化支持，相关补丁已推进数月，初始代码已随 Linux 7.4 合并。技术实现远非平凡；团队还展望未来扩展到更多架构、进一步增强 guest ARM64 能力。
关注理由：大型机 + ARM64 跨架构虚拟化是今年最出人意料的基础设施动向之一；对做虚拟化/异构算力调度的人来说，这是「硬件加速跨 ISA guest」的全新参考实现。
