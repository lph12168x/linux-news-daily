AMD RADV Vulkan 驱动采纳专属 LLM 政策：不禁止但明确劝阻，评审员可酌情关闭 AI 生成的 MR
图形 GPU
继 Mesa 项目层面设有 AI/LLM 贡献政策之后，RADV 驱动现在有了自己的专属政策——由 Valve Linux 图形团队核心开发者、RADV 主要贡献者 Samuel Pitoiset 主动推动，已合入 Mesa Git（MR !45668）。政策要点：
· LLM 辅助的 MR 要求对代码库有充分理解，且评审它们有真实成本，评审员/维护者可自行酌情关闭此类 MR；
· 明确劝阻 LLM 撰写的 issue（往往冗长难读），要求用自己语言描述问题；
· LLM 生成的 bug 复现程序则被允许——前提是提交者本人审查过、且确实能复现该 bug。
Pitoiset 的动机：近来外部贡献者的 LLM MR 开始增多，「最好在被淹没之前把规矩立起来」。
关注理由：RADV 是 AMD GPU 在 Linux 上最主流的 Vulkan 驱动（Steam Deck/SteamOS 也依赖它），这份政策与 Linux 内核「AI/LLM Assisted-by 标签放松」、PostgreSQL 19 因 AI 负担延期等事件同属一条主线：上游项目正从被动承受 AI 补丁洪流转向主动立规。对自研驱动与内部代码评审流程均有直接参考价值。

KDE Linux 临近 Beta 里程碑（完成度约 85%），默认启用 NTSYNC 内核模块改善 Wine/Proton 游戏
显示 Desktop
KDE 开发者 Nate Graham 发布 10 月月报，披露 KDE 官方参考发行版 KDE Linux 的最新状态。开发已逾一年，截至 11 月初完成度约 85%，正在逼近 Beta 里程碑。10 月主要变化：
· 安装器新增基础幻灯片（与其他发行版安装器一致）；
· 内核默认启用 NTSYNC 模块——开箱即改善 Wine/Proton 下 Linux 游戏的体验与性能（NTSYNC 以更接近 Windows 的同步原语取代旧 wineserver 同步路径）；
· wayland-protocols 加入基础镜像，扩展对依赖它的 KDE 项目的支持。
剩余待办：swap 支持、Discover 内更新体验改进、KDE 基础设施变更、更好的双启动处理、Flatpak 崩溃的完善处理等。
关注理由：NTSYNC 默认启用是重要的桌面/游戏信号：它需要内核 6.14+ 的 ntsync 驱动配合，KDE Linux 将其作为默认配置，意味着「Windows 同步原语直通」路线已成为 Linux 游戏栈的既定方向，Wine/Proton 的性能与兼容性基线将被整体抬高。KDE Linux 作为 KDE 官方参考发行版，其 Beta 时点也值得跟踪。

FreeRDP 3.33 发布：WebAssembly 支持就绪可在浏览器中运行，AI 带来的 PR 洪流催生紧急补丁版计划
显示 Remote
开源 RDP（微软远程桌面协议）实现 FreeRDP 发布 3.33 版。多年打磨的 Emscripten/WebAssembly 支持就此就绪——编译为 WASM 后可直接在浏览器中运行 RDP 客户端。其他改进：
· SDL 客户端改进；
· 直连 RDP 新增实验性 UDP 支持；
· Unicode 键盘输入管道获得全部客户端支持；
· 实验性 Windows shadow server 支持；
· macOS 文件剪贴板不再依赖 FUSE；
· 消息翻译初始支持。
项目方同时表示：AI/LLM 带来的 PR 与 bug/回归反馈「洪流巨大」，将很快发布补丁版清理积压的 papercuts 与 bug；本版已含 13 个已知安全修复。
关注理由：远程桌面是显示方向的重要分支：WASM 化意味着 RDP 客户端可以零安装嵌入 Web 页面，对云端工作站、VDI 场景（含 GPU 加速远程渲染）有实际价值。同时它是又一个被 AI 活动「冲到需要紧急补丁版」的项目，与 RADV 立规、内核噪音治理互为印证。
