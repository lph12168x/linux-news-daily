Apple M5 基础支持预计随 Linux 7.5 落地（Device Tree 已入 apple-soc/dt-7.5）
内核 kernel
继 M3 支持（Linux 7.2）与 M4 支持（Linux 7.4）之后，Apple M5 基础型号的极简支持已排队进入 apple-soc/dt-7.5 分支，预计随 Linux 7.5 合并。本次是初始 Device Tree 支持，由 Yureka Lilian 撰写，作者自述只覆盖「最小量的硬件」，作为后续逐代扩展的基础——新增硬件与此前 Apple Silicon 各代基本一致；补丁已由 Sven Peter 排队收编。与 M3/M4 相同，目前仍非常有限，新一代 M 系列的 GPU 支持依然是最大障碍。
关注理由：Apple Silicon 主线化节奏稳定在一年一代；对关注 Asahi 生态与 ARM SoC 上游化的人来说，M5 使能进度是观察其 GPU（DRM）反向工程进展的风向标。

KDE Plasma 6.9 实现 XWayland 按需启动：不再常驻空跑
显示 display
本周 This Week in Plasma 披露：Plasma 6.9 已完成全部工作，XWayland 将只在真正需要时才加载启动——此前即使没有任何应用使用 XWayland，它也会常驻运行，现在终于可以按需拉起，向「默认无 X11 组件」再进一步。其他更新：System Settings 更多页面迁移到 QML；KWin 的「wobbly windows」果动效果用一组趣味预设（water / pudding / molasses / Nitroglycerin + 自定义）取代了原先的摆动滑杆；Spectacle 截图工具启动速度显著优化。同批还有 Plasma 6.8.3 维护版：修复屏保锁崩溃与特定 Intel CPU + NVIDIA GPU 系统的画面损坏。
关注理由：XWayland 按需化是 Wayland 过渡的标志性收尾工作——纯 Wayland 路径已能覆盖 Plasma 全场景；显示子系统/桌面运维团队值得留意 Plasma 6.8.3 的 Intel+NVIDIA 画面损坏修复。

Intel 开始 Coral Rapids 与 Razor Lake 的 Linux 内核使能（首批补丁仅 CPU ID）
计算 compute
继本周四（11-13）的 GCC 初始补丁之后，Intel 工程师 Tony Luck 又提交了 Coral Rapids 与 Razor Lake 的第一批 Linux 内核使能补丁：目前只是最基础的 CPU family / model ID 识别——Coral Rapids（下一代 Xeon 服务器平台）为 Family 19 Model 8；Razor Lake（Nova Lake 继任者）为 Family 18，S/L/U 三个变体各有独立 model ID（10/7/9）。外部分析普遍预计 Razor Lake 面向 2028 年上市、桌面款可能沿用 Nova Lake-S 的 LGA 1954 插槽。两平台目前均无规格与发布时间表，后续补丁会逐步补充 PMU、电源管理、RAS 等。
关注理由：编译器 + 内核同步提前 1~2 年使能，是 Intel 平台「上市即有平滑支持」的保障；对服务器/数据中心采购规划而言，Coral Rapids 进入上游是路线图信号。

Red Hat 为 QEMU 虚拟机改进内存分层：用 NVMe SSD 替代高价 DRAM
计算 compute
KVM Forum 2026（温哥华）上，Red Hat 虚拟化工程师 Peter Xu 介绍了 QEMU 虚拟机内存分层（memory tiering）的改进方案：在当前内存价格居高不下的背景下，让更便宜的 NVMe SSD 在更多场景替代 DRAM，同时保持良好性能。正在评估三条路线：① 新的 maccess(0) 系统调用；② QEMU 全用户态分层（由 QEMU 自己持有慢速层）；③ 利用现有内核 API 做热度迁移——这是当前领跑方案：无需内核改动、QEMU 侧改动小，且可通过一个针对 MADV_PAGEOUT 行为限制的新内核补丁进一步优化。演讲页面与 KVM Forum 视频已公开。
关注理由：内存分层是今年多篇文章的共同主题（此前 AMD MEXT、Dynamic PAMT 均入主线）；虚拟化平台把热数据迁移决策做进 QEMU，对内存成本敏感的大规模 VM 部署是直接利好。

Redox OS 十月进展：Golang 跑通、GIMP 移植成功、AI 政策简化为「拒收 LLM 贡献」
内核 kernel
Rust 编写的 Redox OS 发布十月开发月报：Go 语言工具链首次在该平台跑通——交叉编译与自举编译均可工作，Golang 已适配 Relibc；历经数月移植，GIMP 图像编辑器也成功运行，Servo 浏览器引擎移植同步更新到 Servo 0.7。系统层面：初始 NUMA 支持确认工作正常、修复 RISC-V 动态链接、实现了用户等价路径下的初始无 root 软件包安装。另外社区把 AI 政策简化为一句话：「Redox OS 不接受 LLM（大模型）生成贡献」。
关注理由：Golang 自举 + GIMP 可用说明 Redox 的用户态生态成熟度又上台阶，NUMA 初始支持对服务器方向是积极信号；其明确拒收 AI 生成代码的政策在开源社区争论中颇具代表性。
