AMD ROCm 10.2 发布：新增 18 款 Ryzen 笔记本官方支持，RCCL/推理栈同步优化
计算 compute
AMD 发布开源 GPU 计算栈 ROCm 10.2，这是延续六周节奏的特性版本。推理侧升级 SGLang 与 vLLM 支持，继续推进 Hyperloom、ROCm CLI 与 AMD Skills；性能方面带来 RCCL 针对 PCIe 显卡的改进等优化。最受关注的是本地 AI 覆盖面扩大：新增 18 款采用 gfx1103（RDNA 3）架构的 Ryzen 处理器进入官方支持列表（Ryzen 7 PRO 253/249/217、Ryzen 5 PRO 225/224/216、Ryzen 9 180、Ryzen 7 165/155、Ryzen 5 125 等），Windows 与 Linux 均无需定制构建或特殊配置，并由 HIP、PyTorch、vLLM 的 gfx1103 验证支持背书；同时新增 Radeon PRO W7900D。平台层面扩展 AMD Infinity Storage（AIS）与 hipFile 兼容性，官方支持 RHEL 10.3 / 9.9 与 SLES 16.1。
关注理由：ROCm 正从「服务器 GPU 为主」向笔记本核显的本地 AI 推理延伸：老款 RDNA3 Ryzen 无需折腾即可跑 PyTorch/vLLM，加上 RCCL 的 PCIe 路径优化，对异构计算与端侧推理部署都有实际价值。

Wine 合入远程 OpenGL swapchain 呈现：CEF 应用终于能在原生 Wayland 驱动下正常渲染
显示 display
即将发布的 Wine 11.23 已合入一项对 Wayland 支持意义重大的改动：在 WIN32U 中实现远程 OpenGL swapchain 图像呈现，为使用显示模拟（display emulation）的场景提供 OpenGL 跨进程渲染。该能力在 X11 与 Wayland 下均可工作，但对 Wayland 的提升更明显——此前依赖 Chromium Embedded Framework（CEF）的应用在 Wine 原生 Wayland 驱动 + WineD3D 组合下无法正确渲染，现在可以正常出图。工作由 Wine 开发者 Rémi Bernon主导，经过两周评审后于周二进入 Wine Git（MR !12506），Phoronix 附有 CEF on Wayland 的实际截图。考虑到 Wine 12.0 稳定版将在 2027 年初发布（12 月起进入 RC）、Valve 的 Proton 12.0 也将随之而来，这一步让 Wine 的 Wayland 支持进一步逼近 X11 对等。
关注理由：CEF 被大量桌面应用与游戏启动器/内嵌界面使用，是 Wayland 迁移中长期存在的兼容性硬伤；跨进程 swapchain 呈现打通后，原生 Wayland 下运行 Windows 应用的可用范围明显扩大。

Multikernel Linux 登陆 ARM64：mklinux 7.0-mk5 发布，同机多内核实例进入新架构
内核 kernel
允许在一台物理机上同时运行多个独立内核实例的树外补丁项目 Multikernel Linux 发布新版本 mklinux 7.0-mk5，基于上游 Linux 7.0。最关键的进展是补丁首次扩展到 64 位 ARM（AArch64）——此前仅支持 x86_64。多内核架构的用途包括故障隔离/容错内核、在特定 CPU 核上运行 RT 实时内核，以及其他非传统计算场景；近期还配合 Kmorph 演示过无需重启的 Linux 内核崩溃恢复。本次更新同时改进了设备丢失处理与 DMA 隔离（DMA confinement）、VT-d 集成、链式接管（chained takeovers）等机制。项目以树外补丁形式维护，公告已发往 LKML。
关注理由：同机多内核为实时性与可靠性提供了不同于容器/虚拟机的思路，ARM64 支持意味着这条路线可以覆盖边缘与嵌入式加速器平台；DMA 隔离与接管机制的完善是走向生产可用的关键一环。

Dell XPS 14（Panther Lake）Linux 评测：原生 Ubuntu 26.04 LTS + 2.8K 120Hz OLED，主线内核即开即用
显示 display
Dell 近期为 XPS 14（DA14260）完成 Ubuntu 26.04 LTS 预装认证，Phoronix 对其 Linux 体验给出正面评价。送测机型为 Core Ultra X7 358H（Panther Lake）、32GB LPDDR5x-9600、512GB NVMe，配备 2880×1800 InfinityEdge OLED 触控屏，120Hz、支持 VESA DisplayHDR（基础款为 1920×1200）；整机约 1.4kg、14.6mm，CNC 铝合金 + Gorilla Glass 3，三个 TB4/USB-C 口支持供电与 DisplayPort 2.1。软件栈是重点：预装使用 主线 Linux 7.0 内核 + Mesa 26.0，无需 OEM 内核，摄像头、音频、触觉触控板均开箱可用。200 余项基准测试中，该机性能为同 SoC 的 MSI Prestige 14 Flip 的 1.22 倍，达到旗舰 Core Ultra X9 388H 机型（Framework 13 Pro）的 93%；CPU 平均功耗 23W、峰值 65W。主要短板是价格：该配置约 3000 美元（受内存/SSD 涨价影响）。
关注理由：Panther Lake 的 Arc B390（Xe3）核显与能效在主线内核/ Mesa 下已相当成熟，配合 2.8K 120Hz OLED 与 DP 2.1，是观察「图形/显示栈开箱体验」的代表性样本；升级到更新的内核还能进一步提升图形性能。

AI 内核评审工具 Sashiko 0.9.4：新增实验性「补丁系列设计评估」流水线
内核 kernel
由 Google 工程师开发维护、面向 Linux 内核邮件列表做 agentic AI 代码评审的 Sashiko 发布 v0.9.4。该工具此前主要逐补丁检查正确性与缺陷，默认使用 Gemini 但保持 LLM 无关。本次最值得注意的新功能是实验性的补丁系列设计评估：通过 sashiko review --design 调用一条四阶段评估流水线，从整体上审视整个补丁系列的架构设计，作为既有逐补丁评审的补充，可在本地运行。新版本还加入对 e2fsprogs（EXT4 及前身文件系统的用户态工具）的「一等公民」评审支持，另有若干功能与修复，详见 GitHub 发布页。
关注理由：内核开发中的 AI 应用正从「找 bug」走向「评架构」：当多个项目开始限制 LLM 贡献时，这类面向评审端的设计级辅助工具提供了另一条务实的落地路径，值得关注其准确率与社区接受度。
